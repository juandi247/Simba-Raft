Real Raft
The simulation runs Raft completely inside the engine. It is the same Raft that runs on the deployed nodes, which run the algorithm by sending messages over the network.
Deterministic
Time is a tick counter, and the network and the crashes are simulated. The same seed always produces the same run.
Replayable
If you find a bug or an interesting sequence of events, run it again with the same seed to reproduce it exactly.

Time accelerator

A deterministic simulation does not run on real time. It runs on a simulated clock, which is just a counter. That is one of the big advantages of deterministic simulation testing: time can be accelerated, so you can test the equivalent of hours or days of a real cluster in a fraction of that time. The only limit is how fast your CPU can run the simulation.

0.5× is slower, to follow every message. Normal is the default. 2× runs twice as fast.

Changing the speed does not affect determinism: the same seed always produces the same run.
